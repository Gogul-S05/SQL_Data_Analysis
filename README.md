# Hospital Patient Records Database Management System

## 📌 Project Overview

This project uses **MySQL** to create a Patient Records Database for storing and analyzing healthcare-related information.

The database contains patient details such as age, gender, city, disease, blood pressure, cholesterol, BMI, smoking status, treatment cost, and admission and discharge dates.

## 🛠️ Technologies Used

* MySQL
* SQL
* Data Analysis

## 📊 Database Details

**Database:** `patient_db`

**Table:** `PatientRecords`

### Main Columns

* Patient ID
* Patient Name
* Gender
* Age
* City
* Disease
* Blood Pressure
* Cholesterol
* BMI
* Smoking Status
* Treatment Cost
* Admission Date
* Discharge Date

## 🔍 SQL Analysis

The project can be used to analyze:

* Patient demographics
* Disease distribution
* Blood pressure and cholesterol levels
* BMI patterns
* Smoking status
* Treatment costs
* Patient admission and discharge dates
* Disease-wise patient trends
* Healthcare cost analysis

## 🎯 Objective

The main objective is to practice **SQL database management and healthcare data analysis** using a structured patient dataset.

## 🚀 How to Run

1. Install MySQL.
2. Open MySQL Workbench.
3. Open the SQL script.
4. Execute the complete script.
5. Select the `patient_db` database.
6. Run SQL queries for analysis.
