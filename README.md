# Employee Database Management System

## 📌 Project Overview

This project uses **MySQL** to create and manage an Employee Database. It stores employee details such as name, gender, department, salary, mother tongue, date of birth, joining date, and experience.

## 🛠️ Technologies Used

* MySQL
* SQL

## 📊 Database Details

**Database:** `Employee_db`

**Table:** `employee`

### Main Columns

* Employee ID
* Employee Name
* Gender
* Mother Tongue
* Department
* Salary
* Date of Birth
* Date of Joining
* Experience

## 🔍 SQL Operations

The project demonstrates:

* Retrieving employee records
* Filtering employees by department
* Finding employees based on salary
* Filtering by gender and mother tongue
* Analyzing joining dates
* Filtering employees based on experience
* Using SQL conditions and sorting
* Performing aggregate analysis

## 🎯 Objective

The main objective is to practice **SQL database creation, data management, filtering, and analysis** using a real-world employee dataset.

## 🚀 How to Run

1. Install MySQL.
2. Open MySQL Workbench or another SQL client.
3. Open the SQL script.
4. Execute the complete script.
5. Use the `Employee_db` database to run additional queries.

## 📁 Project File

`Employee_Table_Script(1).sql`

## 👨‍💻 Skills Demonstrated

**SQL | MySQL | Database Management | Data Analysis | Query Writing**

## 🛠️ Technologies Used

* MySQL
* SQL
* Data Analysis

## 📊 Database Details

**Database:** `patient_db`

**Table:** `PatientRecords`

### Main Columns

* Patient ID
* Patient Name
* Gender
* Age
* City
* Disease
* Blood Pressure
* Cholesterol
* BMI
* Smoking Status
* Treatment Cost
* Admission Date
* Discharge Date

## 🔍 SQL Analysis

The project can be used to analyze:

* Patient demographics
* Disease distribution
* Blood pressure and cholesterol levels
* BMI patterns
* Smoking status
* Treatment costs
